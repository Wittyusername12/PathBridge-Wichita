Does it actually work? Can you demo it? Yes: in Find Resources, search the resources loaded from the challenge API by ZIP or keyword, filter them by category, language, cold storage or ID requirement, sort them, and click a card for its details; the Dashboard and Data Explorer tabs draw the same data live in the browser. Find Resources tab
Is it solving a real problem? The Dashboard ranks every ZIP code HIGH, MED or LOW by the data's own primary need metric and lists the crisis events in the data (the store closures and the 311 distress calls), so the hardest-hit areas and the resources still open near them sit on one screen. Dashboard tab
Would real people actually use this? It is made for the people named under "Who this serves": one search box that takes a ZIP or a plain word, filters for what a family needs to know (language, ID required, cold storage), a detail view per site, and a single-column layout on a phone.
